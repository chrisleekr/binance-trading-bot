# User Guide

The reference spine: one page per screen, mirroring the app sidebar. Each page lists the exact fields and labels the app shows, so you can configure with the doc open beside the screen. Following the ordered first-run path instead? Start at [Get started](../get-started/index.md).

## Screens

- **[Dashboard](dashboard.md)** — the home screen: account health, unrealised P/L, positions, market trend, and the profile roster. Where you watch trades and read _why_ the bot acted.
- **[Symbol workspace](symbol-workspace.md)** — one coin in depth: its Trade, Orders, Market, Logs, and Config views.

## Profile

Every section you see when you open a profile, in sidebar order — see the [Profile overview](profile/index.md):

- **[Strategy](profile/strategy.md)** — which strategy runs and all its config knobs.
- **[Risk](profile/risk.md)** — account-wide safety limits.
- **[Live gate](profile/live-gate.md)** — the advisory readiness check before you go live.
- **[Discovery](profile/discovery.md)** — optional auto-rotation of coins.
- **[Notifications](profile/notifications.md)** — where alerts go and which events fire.
- **[Backtest](profile/backtest.md)** — replay the strategy over history before trading it.
- **[History](profile/history.md)** — the profile's past trades, audit, and activity.
- **[Bulk order](profile/bulk-order.md)** — one manual order across every coin.
- **[Profile settings](profile/general.md)** — rename, enable, stop, reconcile fees, and delete.

## Account

Account-level surfaces shared by every profile on the account — see [Account](account/index.md):

- **[API key](account/api-key.md)** — connect the account's Binance key pair.
- **[Dust transfer](account/dust-transfer.md)** — convert tiny balances to BNB.
- **[Orphan orders](account/orphan-orders.md)** — resolve orders no profile is tracking.

## System

Operator-login settings that apply no matter which account is in view:

- **[Settings](system/settings.md)** — timezone, password, and operator-global panels.
- **[Backup & restore](system/backup-restore.md)** — export or restore the whole configuration.
